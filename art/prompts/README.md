# Toad's Great Escape art briefs

These briefs are source direction only. They do not represent uploaded Roblox
assets, approved IDs, or final artwork. Keep every generated image original and
avoid commercial character designs, logos, music, or trade dress.

## Logo

Use case: `logo-brand`

Create a playful Edwardian storybook amusement-ride title mark reading exactly
"TOAD'S GREAT ESCAPE". Use carved painted timber, brass trim, parchment, ivy,
and a small original toad-shaped travel emblem. Warm theatrical lighting,
clear silhouette, readable at Roblox icon scale. No existing entertainment
brand references, no copyrighted characters, no watermark.

## Game icon

Use case: `stylized-concept`

Create a square, high-contrast original game icon: a determined small green
toad silhouette sprinting across a brass-edged storybook map toward a warmly
lit eccentric country hall, with river reeds and a few celebratory sparks.
Edwardian illustration plus toy-theater construction, readable in a tiny
thumbnail. No text, no logos, no recognizable adaptation designs.

## Chapter cards

Create eighteen separate horizontal chapter-card illustrations, one per
canonical chapter in `src/shared/Config/WorldGenConfig.lua`. Each card should
show its own environment and primary mechanic, with a consistent parchment,
ink, brass, and zone-color visual system. Keep the required path readable and
leave safe space for UI title text added in Roblox. No commercial references,
no invented asset IDs, and no text unless supplied as a separate verified
layout layer.

# Tuning guide

`StageDefinitions.lua` owns canonical order, teaching goals, expected novice seconds, path budgets, warning time, periods, assistance and optional token positions. `RoutePlan.lua` owns the numeric required-pad spine used by both generation and tests. Local +X is forward. Main paths are fixed; seed variation must not alter required geometry.

The initial authored spine uses 14-stud landings separated by 2-stud gaps; relief chapters 10, 14 and 18 have contiguous 16-stud landings. Checkpoints are 12x12 and sit above supported finish pads. Every chapter has a catch deck four studs below and a ramp back up. Stage spacing is 16 studs, materialized by a connector once per edge. Zone connectors gain four studs over that run. Spawn and the replay deck have their own constructed connections.

The rewrite deliberately favors a broad visible story spine, placing dangerous timing/vehicle/wind lessons on connected golden detours. Main Caravan pads teach +X conveyors. Existing distant hall, rail-shed and woodland landmarks are preserved, with new chapter silhouettes. Legacy alternate templates live outside Rojo in `experiments/`; they must not enter production without a route contract. The amount of challenge, chapter differentiation and route duration need child playtesting; a simple spine is not evidence of fun or of the 8–12-minute target.

Defaults: conveyor 8 studs/s with 12 studs/s² bounded influence; platform five-second period, train seven; optional bounce 34–38 vertical velocity; timed cycle six seconds with 0.9-second warning; falling root 1.5-second warning and three-second recovery; wind drift influence capped at eight. Rider carry is translation only, never a velocity overwrite, and deduplicated across platforms. Carts are server owned and reset at authored bounds. Catch and connector geometry is never timed away.

Change one parameter at a time. Run `./scripts/check.sh`, both Rojo builds, then the Studio harness and affected manual rows. A changed gap must remain within 4/6/7.5-stud chapter budgets; stable steps within four. Re-run support and lethal-volume validation after changing scenery or landings. Extend `RoutePlan` and its mutation tests together when adding geometry.

Assistance: two failures gives contextual guidance; three gives personal hazard grace; five or 90 seconds offers explicit Help. Reset/fall handling uses local server teleport; the built-in Reset menu also has a one-second respawn configuration. Actual failure-to-control latency requires device/network measurement. Never slow recovery to inflate duration. Assisted runs still celebrate and earn Story/Explorer medals; Toad is a forgiving 90-second unassisted chapter goal. Tokens never gate progress.

UI: core safe insets, fixed 48-pixel minimum primary targets, viewport layout, constrained wrapping text and scrolling settings. Large text changes text bounds rather than enlarging the entire HUD past device edges. String keys start in `Strings.lua`; translated content still needs authoring. In Studio set LocalPlayer's `PseudoLocalization` attribute true to expand dynamic labels. Reduced motion removes cosmetic bob/progress tween; reduced flashes suppresses finale effects; low particles reduces finale bursts and disables ambient emitters. Preserve phase colors when adding contrast cues.

Performance: one connected-player root list/update; no limb queries; one carry and one force application/root/update. Cosmetics are client-local, proximity limited and updated at 10 Hz. Finale particles are bounded bursts with Rate=0. There is no FPS, memory or concurrency benchmark yet. Profile with eight clients and low-end mobile before accepting this budget.
